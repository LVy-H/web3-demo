# Airdrop Module

The standalone `ZkAirdrop` contract was part of the retired on-chain prototype.
It is not part of current Tessera.

Current Tessera is a self-hosted verifiable bulletin board for group decisions.
There is no deployed airdrop contract, token claim flow, chain registry, or
relayer in the active product.

Historical details are preserved in git history and archived design material
only. Do not use this module as a current implementation reference.
